# Способы подключения стилей

В проекте использованы все три способа применения CSS:
- Внешний файл style.css — подключён через <link> в <head>, содержит основные стили страницы
- Внутренний блок <style> — одно правило для секции «Проекты»
- Inline-стиль — font-size: 16px задан непосредственно в атрибуте style кнопки «Отправить»

# CSS-переменные
В :root определены переменные для цветов (бежевый фон, оранжевый акцент, тёмно-коричневый текст) и шрифта

# Позиционирование
- static — явно прописан для заголовка «Навыки».
- relative — обёртка аватара, создаёт точку отсчёта.
- absolute — бейдж «PRO», позиционируется внутри relative-обёртки.
- sticky — навигационная панель «прилипает» к верху экрана при прокрутке.

# Псевдоклассы и состояния элементов
- :hover — при наведении на ссылки навигации цвет плавно меняется на оранжевый, снизу появляется анимированная линия через псевдоэлемент ::after
- :active — изменение цвета в момент клика по ссылкам и кнопке.
- :focus — поля ввода получают оранжевую обводку и свечение при получении фокуса.
- :visited — посещённые ссылки меняют цвет на кремовый.

# Дополнительные возможности CSS3
- Псевдоэлемент ::after — используется для анимированной линии под ссылками навигации.
- Многоколоночная вёрстка — секция «Проекты» отображается в две колонки через column-count.
